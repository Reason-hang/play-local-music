# 当前架构与离线边界

状态：1.7.1；更新时间：2026-08-16。

`MediaStore → Reader/FlowReader → MediaLibrarySession → GramophonePlaybackService → UI/锁屏/蓝牙` 是唯一播放链路。MP4 使用 `MediaExtractor` 确认 AAC 音轨，再以原始视频 URI 构造 `MediaItem`；全屏页仅连接既有 `MediaBrowser`，不创建第二个播放器。内嵌页与全屏页切换时主动释放前一个 `TextureView` 输出，避免同一 ExoPlayer 同时绑定多个视频 `Surface`。

媒体库整理状态位于应用私有 `SharedPreferences` JSON：隐藏项目以 MediaStore ID 和路径 SHA-256 双键保存，并带有仅用于恢复列表显示的媒体标题快照；分类以路径哈希保存。扫描层读取隐藏键并过滤，因此重扫不会回流；恢复动作只删除所选隐藏记录；状态只影响本应用，不删除、移动或写入源文件。单曲使用独立菜单资源，不含物理删除条目；专辑和音乐人菜单也不再暴露媒体删除。

视频断点续播独立于 `LastPlayedManager`：`VideoResumeProgressStore` 为每个视频同时保存 MediaStore ID 与路径哈希两种脱敏身份、时长、修改时间、最近位置和更新时间，不保存标题或原路径。`GramophonePlaybackService` 是唯一读写者：播放中 15 秒节流保存，暂停、视频切换、任务移除与服务销毁立即保存；任一身份命中即可恢复。首页、分类、搜索等自定义命令以媒体展开后的真实 `startIndex` 决定目标项；队列替换前先保存离开视频并取目标进度。仅手动打开视频或队列恢复可一次性 seek，自动下一首与循环不恢复历史位置。文件时长或修改时间变化、超过 180 天、已播放到结尾附近时记录失效；最多保留 500 条。因此 MP3 进度与队列恢复保持原有职责，不会被视频历史覆盖。

外放强音复用 `ReplayGainAudioProcessor` 的 PCM Float 动态压缩路径：开关开启后固定叠加 4 dB 安全增益，并以 -10 dB 阈值压缩峰值，避免向系统请求超过媒体音量上限的音量。该处理链路对 MP3 和 MP4 音轨统一生效，不创建新播放器、不触碰 `MediaSession`、视频 `Surface` 或锁屏服务；由于需要 PCM 处理，音频 Offload 不适用。它优化感知响度，不承诺超出手机扬声器硬件能力。

产品变体使用同一代码和播放链路：`localDebug` 的包名为 `org.akanework.gramophone.debug`，名称“本地听歌”；`courseDebug` 加 `.course` 后缀，名称“多听课程”并覆写启动图标。两个包的应用私有数据、视频进度、分类和隐藏记录相互隔离。

离线方案 B：主清单不声明 `INTERNET`，移除网络状态权限和可见在线入口；诊断不会自动上传。底层保留的历史依赖不构成“全部源码无网络代码”的承诺，飞行模式仍须真机验证。
