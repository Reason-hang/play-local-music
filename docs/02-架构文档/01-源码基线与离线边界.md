## 第一章 源码基线

源码来自上游 `FoedusProgramme/Gramophone` 的 `beta` 分支，当前基线提交为 `eacd986`；本地产品名称统一为“本地听歌”。依赖子模块为 HiFiCore 的 libusb-cmake 和 Media3 `d87a9c0`。本地改动只触及权限、可见入口、资源文案、媒体扫描和构建 SDK 口径，不重构播放器架构。

MP4 支持沿用既有 Media3 `Mp4Extractor`/`FragmentedMp4Extractor` 与 `GramophonePlaybackService`。扫描层单独查询 `MediaStore.Video`，再使用系统 `MediaExtractor` 确认存在 `audio/mp4a-latm`（AAC）轨道；符合项以原始视频 URI 作为 `MediaItem`，交给既有音频渲染、队列和 `MediaLibrarySession`。渲染工厂继续不创建视频渲染器，因此不显示画面。Android 13+ 额外声明并请求 `READ_MEDIA_VIDEO`，该权限只为读取用户本地 MP4 文件，不引入网络能力。

## 第二章 离线边界

方案 B 的实现是删除网络和图片权限、移除外链更新入口、关闭均衡器/歌词/封面入口，同时保留底层实现以降低改动风险。核心本地扫描、播放、队列、播放列表、后台和媒体控制路径不主动发起网络请求。

## 第三章 兼容口径

Android 16 对应 API 36；本地构建将 `compileSdk` 与 `targetSdk` 固定为 36。目标机型为红米 K80 Pro/HyperOS。静态构建成功不等于该机型的后台、锁屏、蓝牙和声音验收成功，后者必须单独记录。
