# 诊断与故障恢复设计

状态：1.6.0；更新时间：2026-08-12。

## 设计

- 未捕获异常写入 `filesDir/diagnostics/crash_<timestamp>.txt`；最多 20 条，单条最多 64 KiB。
- 正常事件保存为有界 JSONL；播放状态、播放意图、媒体切换和播放器错误均会记录 MIME、状态和原因，但诊断失败不能阻塞播放。
- 剪贴板摘要取最近 20 条事件，每条最多 1,024 个字符。文本进入存储、剪贴板和 ZIP 前均脱敏本地路径与 `content://` URI；不记录媒体标题、完整 URI、用户输入或剪贴板内容。
- 设置页提供两个明确动作：**一键复制诊断摘要**与**导出完整诊断包**。没有“分享摘要”、自动邮件或自动网络发送。
- 视频续播事件只记录是否恢复、恢复秒数和 MIME，不记录视频标题、文件路径或 URI；用于区分“没有触发恢复”与“恢复到了错误记录”。

## 故障恢复

“行为设置”历史 NPE 的根因是 XML 节点被裁剪后 Kotlin 仍使用 `findPreference(...)!!`。本版保持声明式权限裁剪并已清理孤儿调用。后续裁剪 Preference 时必须做 key 全局引用检索，并对每个保留设置页做点击冒烟。

用户遇到问题时，先复制摘要给开发排查；只有需要完整历史时再导出 ZIP。若诊断页本身异常，不影响播放器和本地文件。
