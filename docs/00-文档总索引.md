## 阅读顺序

1. 从《产品范围与验收》确认本版交付边界。
2. 从《当前架构与离线边界》理解 MP3、MP4、后台播放和隐私约束。
3. 根据《构建与签名》复现 APK；以《验证记录》区分已验证与待验证事项。
4. 排障时先看《诊断与故障恢复设计》与《通用自主决策记录》。
