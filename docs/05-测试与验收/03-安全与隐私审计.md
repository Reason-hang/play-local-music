# 安全与隐私审计

状态：1.7.1 静态审计；更新时间：2026-08-16。

## 结论

本轮代码范围内未发现需要立即停止交付的明文密钥、自动外发诊断或 `INTERNET` 清单权限。结论只覆盖本地源码与清单，不能替代联网依赖漏洞数据库和真机运行时审计。

## 已落实的控制

| 风险 | 控制 |
| --- | --- |
| 网络与统计 | 主清单不声明 `INTERNET`，无自动诊断上传入口。 |
| 本地媒体隐私 | 隐藏/分类仅存 MediaStore ID、路径哈希与恢复列表所需标题快照；不复制、移动或删除源文件。 |
| 视频续播隐私 | 仅存应用私有的视频身份哈希、时长、修改时间、位置和更新时间；不存标题、原始路径或音频进度。 |
| 外放强音 | 仅保存用户开关状态；PCM 只在内存中处理，不保存音频、波形、设备标识或媒体内容。 |
| 诊断泄露 | 路径与 `content://` URI 脱敏、应用私有目录、有界大小、用户显式复制或导出。 |
| 导出 | `FileProvider` 仅对用户主动生成的 ZIP 临时授予读取权限。 |
| 启动器攻击面 | 用户交付变体只保留主 `MAIN/LAUNCHER` Activity。 |

## 未闭环

- 正式签名密钥管理与正式版升级链路需要用户提供 keystore 后单独验收。
- 第三方依赖 CVE 需要可联网的依赖扫描；不可把“本地未发现”表述为“无漏洞”。
- 原生解码器和厂商系统策略需要设备测试。
