## 审计范围和未覆盖范围

已审计：`GramophonePlaybackService`、`DiagnosticStore`、`DiagnosticsSettingsFragment`、`Reader` 音频/视频 MediaStore 扫描、`VideoResumeProgressStore`、`QueueBoard`、`LocalLibraryManager`、应用清单、构建变体、离线权限和测试目录。

未覆盖：连接 Redmi 24122RKC7C 的真实操作、锁屏/通知栏/蓝牙硬件事件、HyperOS 后台策略、真实 HEVC/AAC `MediaCodec` 能力、正式 keystore 签名与商店升级链路。仓库没有可运行的 Android instrumentation 测试设备，本报告不把 Robolectric 或 APK 结构检查写成真机结论。

## 技术栈和模块概览

应用为 Kotlin + Media3/ExoPlayer + `MediaLibraryService`。扫描器通过 MediaStore 产生 MP3/MP4 `MediaItem`；`GramophonePlaybackService` 持有唯一播放器、MediaSession 和后台服务；`DiagnosticStore` 使用应用私有目录保存脱敏 JSONL/崩溃摘要；`VideoResumeProgressStore` 使用应用私有 SharedPreferences 保存每个视频的独立进度。两个产品 Flavor 共享逻辑，仅包名、名称、图标和主题资源不同。

## 安全问题清单

审计确认：两个 APK 清单均不含 `INTERNET`、`ACCESS_NETWORK_STATE` 实际权限；诊断目录位于 `filesDir`，复制/导出均由用户主动触发；路径与 `content://` URI 有脱敏；媒体库移出只写应用私有隐藏状态，不删除手机文件；FileProvider 未导出。

仍存在的限制：底层歌词/封面/均衡器依赖按方案 B 保留，未做全面依赖清理；正式 keystore 未配置，SelfBuilt 包不等于商店发布签名；第三方依赖 CVE 未在离线环境进行联网数据库扫描。

## 性能与稳定性问题清单

已修复：诊断普通事件异步写盘、诊断 UI 文件操作移到 I/O、媒体扫描空值防御、MediaSession malformed 命令返回错误。

仍存在的限制：`Reader` 对无法得到传统绝对路径的音频行会跳过；视频 `MediaExtractor` 探测在大曲库中仍有 I/O 成本；这些行为需要真实大媒体库和设备性能数据后再优化，不在本次扩大范围。

## 架构与可维护性问题清单

审计结论：播放器、队列、视频续播和诊断的分层边界基本成立；本次没有引入第二播放器或全局跨模块状态。诊断事件模型仍是轻量 JSONL 工具对象，符合个人离线工具规模。后续可将 MediaSession 自定义命令白名单抽成纯函数并增加集成测试，但不是本次发布阻断项。

## 数据一致性问题清单

应用私有状态的事件、崩溃、视频进度、隐藏媒体和分类均按变体包名隔离；清理诊断不会删除媒体；卸载应用会清理私有状态但不会删除手机文件。`VideoResumeProgressStore` 对时长/修改时间变化安全失效，避免把旧进度套到被替换文件。

## 上线阻断项

本机自动化没有发现新的编译、单测或 Lint error；但若交付目标包含“Redmi/HyperOS 锁屏、视频画面和外放强音已实测”，当前仍有阻断：设备未连接，必须完成真机矩阵后才能宣称硬件通过。正式商店发布另有签名阻断，不由本次 SelfBuilt 修复解决。

## 建议观察项

- 普通诊断事件异步化后，进程被系统立即杀死时最后一条普通事件可能丢失；崩溃摘要同步保存，用户仍可复制最近完整摘要。
- `controller.isTrusted` 的系统判定需在 Android 16/HyperOS 上确认；标准播放控制应保持可用，自定义队列功能只给应用可信控制器。
- 空 DATA 行被跳过是当前文件管线的安全选择；若未来要支持纯 URI 音频，需要新增 URI 读取链路和权限验收。

## 可接受的残余风险

在无网络、无账号的本地播放器中，无法通过静态代码证明所有硬件厂商行为。当前残余风险集中在 HyperOS 的服务回收、视频硬解/输出面、扬声器主观响度、系统媒体控制器判定和正式签名升级；均已有明确真机或发布前验证动作，不应被包装成已通过。

## 最终审计结论

代码审计发现的 5 项真实问题已完成最小修复：普通诊断写盘异步化、诊断 UI 生命周期安全化、音频扫描空值防御、MediaSession 自定义命令权限/参数校验、启动日志脱敏。版本升级为 1.7.2；双变体自动化验证通过后可形成新的 SelfBuilt APK。源码层面未发现会阻断 MP3/MP4 播放、队列、锁屏后台或手机文件安全语义的新增缺陷；真机硬件验收和正式签名仍是明确未覆盖项。
