# 安装诊断与交付

状态：1.6.2；更新时间：2026-08-13。

安装包：`outputs/本地听歌-1.6.2.apk` 用于覆盖同包名旧版本；`outputs/多听课程-1.6.2.apk` 使用独立包名，可直接与前者同时安装。课程版首次安装或更新后，锁屏/通知栏可能缓存旧应用图标，结束该媒体通知后重新开始播放即可刷新。若系统提示签名不一致，先导出诊断包和当前版本信息，再卸载同包旧版本后安装。卸载会清除该应用私有的隐藏媒体、分类与视频续播记录，但不会删除手机音视频文件；两个应用之间也不共享这些记录。校验值以《验证记录》为准。

异常处理顺序：设置 → 诊断与日志 → 一键复制诊断摘要；只有需要完整历史时再导出 ZIP。若视频续播异常，记录视频 A/B 的切换方式、上次播放秒数、重开后的秒数和是否已播到末尾；若视频无画面，先确认文件是 MP4 + AAC，并把诊断摘要与复现步骤一并提供。
