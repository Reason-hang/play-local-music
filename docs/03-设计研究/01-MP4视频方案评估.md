## 候选方案

| 方案 | 说明 | 代价 |
|---|---|---|
| A | 新建独立视频播放器 | 队列、后台和媒体会话重复，超出 MVP |
| B | 保持仅音频 | 风险最低，但不能满足 MP4 有画面需求 |
| C | 为现有 ExoPlayer 启用视频渲染，并在完整播放器绑定 `PlayerView` | 复用队列、服务和控制，改动集中 |

## 推荐方案

采用 C。它保持单一播放实例和单向依赖：扫描层只表达媒体类型，播放服务负责解码，UI 只绑定现有 MediaBrowser。视频表面在完整播放器可见时绑定；锁屏后 UI 消失但媒体服务继续输出 AAC 声音。

## 验收边界

本版重点验证 MP4 容器中的 AAC、常见 H.264/HEVC 视频轨、开始播放、切歌和熄屏音频。不同厂商的硬件解码器对极高码率、10-bit、HDR、DRM 或非 AAC 音轨的结果不作为本版承诺。
