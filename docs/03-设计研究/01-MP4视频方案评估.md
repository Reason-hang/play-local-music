# MP4 视频方案评估

状态：1.4.0 已采用方案；更新时间：2026-08-10。

| 方案 | 结论 |
| --- | --- |
| 新建视频播放器项目 | 不采用：播放状态、锁屏和队列会分叉，违反最小改动原则。 |
| 只播放 MP4 音轨 | 已完成历史阶段，但不能满足看画面。 |
| 复用 Media3 播放器并增加全屏渲染页 | 已采用：同一 MediaSession、同一队列、同一前台服务，MP4 + AAC 首要验收。 |

实现：`Reader` 查询 `MediaStore.Video`，用 `MediaExtractor` 检查 `audio/mp4a-latm`，命中后加入媒体库。播放页显示嵌入式画面；点击画面进入横屏全屏 `PlayerView`。全屏只控制渲染面，后台/锁屏继续由服务处理。

边界：MP4 是容器，非 AAC 音轨可能不进入媒体库；画面可否硬解、横竖比例与 HyperOS 后台策略都须红米 K80 Pro 真机验证。
