## 版本详情

### v1.7.2

- 本次最重要变化：完成离线诊断、媒体扫描和 MediaSession 边界加固。
- 新增：无（审计修复补丁）。
- 修改：普通诊断事件改为异步写盘；崩溃摘要保持同步落盘；诊断设置页 I/O 脱离主线程；启动日志仅记录脱敏字段。
- 修复：MediaStore 缺失路径不再触发空值崩溃；自定义 MediaSession 命令增加可信控制器、标题和起始索引校验；诊断生命周期边界得到加固。
- 删除：无。
- 受影响功能：诊断设置、播放服务、媒体扫描、MediaSession 控制和启动日志。
- 数据与文件影响：不修改用户媒体文件；诊断记录保存在应用私有目录，崩溃摘要同步写入以保留故障证据。
- 提交 SHA：`cdd707be5f35adfb855e1585571756f8ec417517`
- 验证与交付：双变体各 61 项单元测试通过，Lint 为 0 error；1.7.2 APK 完成包名、版本、离线权限和 ZIP 校验。未连接 Redmi K80 Pro，锁屏、HyperOS 后台、硬件解码和外放主观效果待真机验收。核心审计代码由 `12356c4` 承载，版本号与验证记录由上述提交承载。

- 修改：主题色、列表卡片布局、课程 Logo、播放页和相关文档入口。
- 修复：无（主要为视觉改造）。
- 删除：无。

- 数据与文件影响：不修改用户媒体文件、播放队列或应用业务数据。
- 提交 SHA：`543d06a9f64c65761625ea90d4235f865e0a0f2a`

### v1.7.4

- 本次最重要变化：扩大原生 Compose 壳覆盖范围，重构主要页面的视觉承载层。
- 新增：`NativeVisualShell`、原生首页与页面壳。
- 修改：首页、播放页、媒体库整理、诊断与日志入口的视觉渲染；课程和本地主题色继续区分；保留 XML 兼容层。
- 修复：无（主要为视觉重构）。

### v1.7.5

- 本次最重要变化：统一竖屏与横屏倍速，并修复设置 2× 后进入全屏的崩溃。
- 新增：`PlaybackSpeedPolicy` 唯一速度策略、共享 `PlaybackSpeedDialog` 和全屏自有倍速按钮。
- 修改：竖屏与全屏均操作同一 MediaSession 代理 Player；产品速度固定为 0.75/1/1.3/1.5/1.7/2×；全屏控制器移除 Media3 原生设置入口。
- 修复：Media3 固定七项速度与项目六项文案不一致导致的 `ArrayIndexOutOfBoundsException`；旧 1.25× 状态归一为 1.3×。
- 删除：Media3 原生设置入口和项目对其六项速度资源的覆盖路径。
- 受影响功能：视频播放页、全屏切换、倍速状态和横竖屏旋转。
- 数据与文件影响：不修改 MP3、视频文件、播放队列或断点续播数据；只对旧播放参数做产品预设归一。
- 提交 SHA：`c6a42faccbb6a18073fce494f5a6f3406ae3809c`
- 验证与交付：双变体各 66 项单元测试通过，Lint 为 0 error；两个 1.7.5 APK 已完成包名、版本、离线权限、签名、zipalign 和 ZIP 完整性校验。未连接 Redmi K80 Pro，竖屏设 2×、进入全屏、返回、锁屏后台和硬件解码仍待真机验收。

### v1.7.6

- 本次最重要变化：单条崩溃摘要可一键复制，也可长按选择部分文本，便于快速反馈完整故障证据。
- 新增：详情弹窗“复制此崩溃摘要”按钮；正文启用文本选择。
- 修改：页面级“一键复制诊断摘要”与单条复制复用统一剪贴板方法；单条复制使用 `DiagnosticStore.readCrash()` 返回的已脱敏内容。
- 修复：详情弹窗只有“确定”且无法复制、无法选择文本的交互缺口。
- 删除：无。
- 受影响功能：诊断与日志页面、单条崩溃详情弹窗和剪贴板反馈。
- 数据与文件影响：不修改用户媒体文件；只有用户点击复制或主动选择时，已脱敏诊断文本才进入系统剪贴板；不新增网络访问或自动外发。
- 提交 SHA：`b51cd6647979809e7fbf631bd2ea2c34b8ab5405`
- 验证与交付：双变体各 68 项单元测试通过，共 136 项，0 失败、0 错误；Lint 为 0 error，本地/课程分别有 132/139 条既有 warning。两个 1.7.6 APK 已完成包名、版本、离线权限、签名、zipalign 和 ZIP 完整性校验。当前仍未连接 Redmi K80 Pro，按钮显示、长按选择、剪贴板内容和倍速全屏链路待真机验收。

## 版本链路补充

- 版本号并非单调提交链：`v1.7.2` 为 versionCode 37，`v1.7.3` 为 38，`v1.7.4` 为 39；回滚后恢复 `v1.7.2` 的 versionCode 37，再发布 `v1.7.5` 的 versionCode 38，当前 `v1.7.6` 为 versionCode 39。
- `v1.7.3` 和 `v1.7.4` 虽有构建与静态验证证据，但已被撤回；不能将它们视为当前用户应安装的版本。
- 当前版本记录只记录源码、Git、测试和 APK 静态证据；没有把 Robolectric、构建成功或 ADB 无设备状态写成 Redmi K80 Pro 真机通过。
