## 环境要求

## 构建命令

在仓库根目录执行：

```bash
JAVA_HOME=/path/to/jdk-21 \
ANDROID_HOME=/path/to/android-sdk \
./gradlew --no-configuration-cache --no-parallel :app:assembleNonMinifiedRelease
```

实际结果：退出码 0，生成 `app/build/outputs/apk/nonMinifiedRelease/本地听歌-1.1.2.19c8a81-nonMinifiedRelease.apk`。该交付变体是 Release 构建但使用 Android 默认 debug 签名，因为未提供正式私钥；签名可验证且可安装，不等同于发布商正式签名。APK 应用标签已核验为“本地听歌”。
