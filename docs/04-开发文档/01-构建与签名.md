# 构建与签名

状态：1.7.3；更新时间：2026-08-22。

本机使用 JDK 21、Android SDK 36。构建命令：

```bash
./gradlew :app:testLocalDebugUnitTest :app:lintLocalDebug :app:assembleLocalDebug :app:assembleCourseDebug
```

`localNonMinifiedRelease` 保留 `org.akanework.gramophone`，用于覆盖已安装的“本地听歌”；`courseNonMinifiedRelease` 使用 `org.akanework.gramophone.course`，可与前者同时安装。当前为 versionCode 38、versionName `1.7.3`；产物对外复制为 `outputs/本地听歌-1.7.3.apk` 与 `outputs/多听课程-1.7.3.apk`，文件名不含 `debug`。该构建类型不启用代码混淆但使用可复现的 SelfBuilt 签名配置；若正式 keystore 未配置，不得宣称为商店 Release。

未提供正式 keystore 前，APK 是 SelfBuilt 签名。生产发布需要用户提供并安全保管私钥，随后重新验证签名和从当前包到正式包的升级路径。
