# 构建与签名

状态：1.4.1；更新时间：2026-08-10。

本机使用 JDK 21、Android SDK 36。构建命令：

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

交付变体保留 `org.akanework.gramophone.debug`，以覆盖用户已安装版本；`isDebuggable=false`，不包含旧 StrictMode 弹窗、LeakCanary 或 Reflections 启动器。产物对外复制为 `outputs/本地听歌-1.4.1.apk`，不得以文件名暗示正式 release。

未提供正式 keystore 前，APK 是 SelfBuilt 签名。生产发布需要用户提供并安全保管私钥，随后重新验证签名和从当前包到正式包的升级路径。
