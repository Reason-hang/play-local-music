# 构建与签名

状态：1.7.2；更新时间：2026-08-20。

本机使用 JDK 21、Android SDK 36。构建命令：

```bash
./gradlew :app:testLocalDebugUnitTest :app:lintLocalDebug :app:assembleLocalDebug :app:assembleCourseDebug
```

`localDebug` 保留 `org.akanework.gramophone.debug`，以覆盖用户已安装版本；`courseDebug` 使用 `org.akanework.gramophone.course.debug`，可与前者同时安装。二者均设为 `isDebuggable=false`，不包含旧 StrictMode 弹窗、LeakCanary 或 Reflections 启动器。当前为 versionCode 37、versionName `1.7.2`；产物对外复制为 `outputs/本地听歌-1.7.2.apk` 与 `outputs/多听课程-1.7.2.apk`，文件名不含 `debug`，也不得暗示正式商店 Release。

未提供正式 keystore 前，APK 是 SelfBuilt 签名。生产发布需要用户提供并安全保管私钥，随后重新验证签名和从当前包到正式包的升级路径。
