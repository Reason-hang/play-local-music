# 构建与签名

状态：1.7.5；更新时间：2026-08-28。

本机使用 JDK 21、Android SDK 36。1.7.5 交付构建命令：

```bash
./gradlew :app:testLocalDebugUnitTest :app:testCourseDebugUnitTest :app:lintLocalNonMinifiedRelease :app:lintCourseNonMinifiedRelease :app:assembleLocalNonMinifiedRelease :app:assembleCourseNonMinifiedRelease
```

`localNonMinifiedRelease` 使用 `org.akanework.gramophone`，`courseNonMinifiedRelease` 使用 `org.akanework.gramophone.course`，可同时安装。二者均为 `isDebuggable=false` 的 SelfBuilt 交付变体，不包含旧 StrictMode 弹窗、LeakCanary 或 Reflections 启动器。当前为 versionCode 38、versionName `1.7.5`；产物对外复制为 `outputs/本地听歌-1.7.5.apk` 与 `outputs/多听课程-1.7.5.apk`，文件名不含 `debug`。

常规 `release` 变体需要未提供的私有 keystore；本次使用项目已有 `nonMinifiedRelease` 交付变体，以 Android debug key 签名但保持 `isDebuggable=false` 和 Release 资源配置。APK 是 SelfBuilt 安装包，不等同于正式商店签名；生产发布需要用户提供并安全保管私钥，随后重新验证签名和从当前包到正式包的升级路径。
