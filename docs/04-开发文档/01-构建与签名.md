# 构建与签名

状态：当前源码 1.7.10／43；双 Flavor 自动化和 Release Lint 已执行，审计兼容补修后的最终复验已通过；正式双包待从固定源码构建，元数据验收结果以本轮证据清单为准。更新时间：2026-10-10。

在仓库根目录执行，使用本机 JDK 21 和 Android SDK 36。先测试与静态检查，再从已提交的内容提交构建，重型任务串行运行：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
./gradlew :app:testLocalDebugUnitTest :app:testCourseDebugUnitTest :app:lintLocalNonMinifiedRelease :app:lintCourseNonMinifiedRelease --no-parallel --max-workers=1 '-Dorg.gradle.jvmargs=-Xmx2g -Dfile.encoding=UTF-8 -XX:+UseParallelGC'
./gradlew :app:assembleLocalNonMinifiedRelease :app:assembleCourseNonMinifiedRelease --no-parallel --max-workers=1 '-Dorg.gradle.jvmargs=-Xmx2g -Dfile.encoding=UTF-8 -XX:+UseParallelGC'
```

| 变体 | 包名 | 交付文件 |
| --- | --- | --- |
| localNonMinifiedRelease | org.akanework.gramophone | outputs/本地听歌-1.7.10.apk |
| courseNonMinifiedRelease | org.akanework.gramophone.course | outputs/多听课程-1.7.10.apk |

二者可同时安装，版本号均为 1.7.10／43。使用项目既有 nonMinifiedRelease SelfBuilt 配置，签名为 Android debug key，Release manifest 不可调试；签名类型与 debuggable 属性分别核验。常规 release 需要未提供的私有 keystore。

验包须校验包名／版本、variantName、debuggable、权限、ZIP CRC、4 字节及原生库 ZIP 16 KiB 页对齐、v1／v2 签名和唯一签名证书；与本地已保存的 1.7.7 比较证书。签名匹配是覆盖安装必要条件，不能替代 Redmi 上的升级及数据保留验收。ZIP 页对齐也不等同 ELF 或真机兼容性验收。

内容提交 A 固定构建源码；后续证据提交 B 记录 A、构建日志及 APK 哈希，不预写自身 SHA。两包完成全部验包后才复制交付，旧安装包保留；outputs 不提交 Git。[版本台账](版本记录表.md)和[本轮证据](../05-测试与验收/evidence/1.7.10/)记录实际结果。SelfBuilt 交付不等同 GitHub Release 或商店发布。
