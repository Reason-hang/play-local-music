## 环境

- Android SDK Platform 36.1，Build Tools 36.0.0。
- 可用 JDK；本次编译环境为 OpenJDK 26，Gradle 会提示 Kotlin 的 JVM target 兼容警告，非本次代码错误。
- 初始化的 `media3` 与 `hificore` 子模块。

## 构建命令

在仓库根目录执行：

```bash
JAVA_HOME=/path/to/jdk \
ANDROID_HOME=/path/to/android-sdk \
ANDROID_SDK_ROOT=/path/to/android-sdk \
./gradlew --console=plain :app:assembleDebug
```

预期结果：生成 `app/build/outputs/apk/debug/` 下以“本地听歌”开头的 APK。当前正式 Release 构建被上游 Media3 的 Release 依赖编译错误阻断；实际命令与 SHA-256 记录在[验证记录](../05-测试与验收/01-验证记录.md)。

## 签名边界

`nonMinifiedRelease` 是便于内部诊断的发布变体；当前未提供正式 release keystore，因此 APK 使用 Android 默认 debug 签名。它可安装用于同一签名链的内部测试，不能冒充商店发布包。接入正式签名前应备份私钥、配置 CI 密钥注入、验证从已安装包的升级路径。

## 发布前检查

1. 运行定向单元测试、全量单元测试、Lint 和 Release 构建。
2. 用 `apksigner verify --verbose` 与 `zipalign -c -P 4 -v 4` 校验产物。
3. 在目标机安装并执行[产品验收](../01-产品文档/01-产品范围与验收.md#验收标准)。
