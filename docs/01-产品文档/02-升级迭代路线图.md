## 审计复核后任务

| 优先级 | 工作项 | 当前判定 | 验收方式 | 估时 |
|---|---|---|---|---:|
| P1 | 诊断导出生命周期与主线程读取 | 源码直接证实：导出协程未绑定 Fragment 生命周期，崩溃记录读取在主线程；应改为 `viewLifecycleOwner.lifecycleScope` + IO 读取 | “导出后立即返回”不崩溃；列表和详情不在主线程读文件 | 0.5 人日 |
| P1 | 诊断脱敏与容量边界 | 路径含空格的正则边界真实存在，但当前播放器错误链未证实会携带路径；按防御性加固处理 | 含空格路径、`file://`、`content://`、超长详情单测 | 0.5 人日 |
| P2 | MP4 大媒体库性能 | 每个候选 MP4 会做 `MediaExtractor` 探测，且全媒体观察源可能触发重扫；实际影响未获真机数据 | 大视频库与高频拍照前后 CPU、耗时、耗电对比 | 0.5～1 人日 |
| P2 | 设置 XML 与 Kotlin 引用防回归 | 其余 5 个 `findPreference(...)!!` 当前有对应节点，不是现存故障；未来裁剪时有复发风险 | 所有保留设置页启动冒烟；变更前 key 引用检查 | 0.25～0.5 人日 |
| P2 | SelfBuilt 到正式 Release | `nonMinifiedRelease` 已构建通过，但仍是默认 debug 签名；私钥与签名升级路径未闭环 | 私钥签名、从旧包升级、zipalign 与签名校验 | 0.5～1 人日（不含密钥提供） |
| P3 | 诊断存储边界与旧版备份规则 | 崩溃写入/清除竞态、总长度、导出 ZIP 清理、Android 6–11 备份规则均为低概率或非目标机项 | 单测 + 存储压力检查 | 0.5 人日 |
| P3 | 原生 C++ 专项审计 | 不是已确认漏洞，而是两份报告都未覆盖的高风险面 | 输入边界、JNI、动态加载、USB 描述符专项审计 | 2～4 人日 |

## 估时与验收

快速闭环是 1.3.3 用户阻断修复和 P0 真机回归，预计 0.5～1 人日。完整上线版包含 P0、P1 和正式签名，预计 3～5 人日；不包含 P3 的原生层专项审计。每项以真实机型日志、可复现步骤、APK 校验和回归记录为验收证据。
