# 产品范围与验收

状态：1.5.0；更新时间：2026-08-12。

## 已纳入范围

| 模块 | 当前行为 | 验收重点 |
| --- | --- | --- |
| 本地播放 | MP3；MP4 容器内 AAC 音轨 | 扫描、播放、切歌、队列 |
| 视频 | 播放页内预览；点击进入横屏全屏；同一时刻仅绑定一个视频输出 | 竖屏有画面、全屏画面连续、返回后进度和队列连续 |
| 后台 | 既有前台媒体服务与 MediaSession | 熄屏、通知栏、蓝牙 |
| 首页 | 三行歌曲主标题、小字号、无副标题；移除专辑/流派/发行日期标签；骰子图标表示随机播放 | 长标题可读、标签数量收敛、图标含义直观 |
| 整理 | MP3/MP4 筛选；分类多归属；单曲菜单和整理页均可非破坏性移出；已移除内容可多选恢复 | 重扫后隐藏不回流，手机文件不变 |
| 诊断 | 复制脱敏摘要及最近 20 条播放状态；用户主动导出 ZIP | 无自动外发、无路径、URI 或标题泄露 |

## 不在范围

- 不支持在线歌词、封面下载、更新检查或网络依赖。
- 不承诺所有 MP4 编码；首要验收为 MP4 + AAC。
- 不删除手机源文件，不实现文件移动。
- 不新增多队列或定制队列恢复架构。
- 未配置正式 release keystore，不作为商店发布产物。

## 用户验收步骤

1. 安装新包覆盖旧包，确认仅一个“本地听歌”图标且图标保持原主图标。
2. 首次进入主页确认 MP3/MP4 都可见；切换 MP3、MP4、分类筛选。
3. 在“媒体库整理”中勾选项目加入两个分类；确认“全部”仍显示所有未隐藏项目。
4. 在单曲菜单选择“从媒体库移除（不删除手机文件）”，确认不会出现系统删除文件授权；刷新媒体库后确认不显示；在“已移除内容”勾选恢复，确认仅恢复所选内容且文件从未删除。
5. 播放 MP4，确认竖屏画面；点击画面进入全屏并返回；锁屏后确认声音、通知栏和上一首/下一首仍正确。
6. 打开“诊断与日志”，确认可复制摘要并可按需导出 ZIP。
