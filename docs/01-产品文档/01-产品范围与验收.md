# 产品范围与验收

状态：1.7.2；更新时间：2026-08-22。

## 已纳入范围

| 模块 | 当前行为 | 验收重点 |
| --- | --- | --- |
| 本地播放 | MP3；MP4 容器内 AAC 音轨 | 扫描、播放、切歌、队列 |
| 视频 | 播放页内预览；点击进入横屏全屏；同一时刻仅绑定一个视频输出；每个视频以 MediaStore ID 与路径哈希双身份独立断点续播 | 竖屏有画面、全屏画面连续、返回后进度和队列连续；从首页、分类、搜索、队列手动重开均恢复正确位置 |
| 外放强音 | 设置 → 播放选项中的默认关闭开关；使用 PCM 动态压缩与 4 dB 安全增益提升手机扬声器的感知响度 | MP3、MP4 音轨均可开关；满媒体音量下无异常中断或明显破音；蓝牙/有线耳机回归不受影响 |
| 后台 | 既有前台媒体服务与 MediaSession | 熄屏、通知栏、蓝牙 |
| 首页 | 三行歌曲主标题、小字号、无副标题；移除专辑/流派/发行日期标签；紧凑模式使用更低行高；骰子图标表示随机播放 | 长标题可读、标签数量收敛、紧凑模式密度和图标含义直观 |
| 整理 | MP3/MP4 筛选；分类多归属；单曲菜单和整理页均可非破坏性移出；已移除内容可多选恢复 | 重扫后隐藏不回流，手机文件不变；早期记录显示为“历史移除记录” |
| 双应用 | “本地听歌”与“多听课程”使用不同应用 ID 和本地状态；课程版固定火焰橙 `#FF4E00`，使用白底居中的橙色耳机图标 | 同机可同时显示两个图标、课程版图标同时用于启动、锁屏大图与通知小图标、互不覆盖、互不共享隐藏/进度/分类记录 |
| 诊断 | 复制脱敏摘要及最近 20 条播放状态；用户主动导出 ZIP | 无自动外发、无路径、URI 或标题泄露 |

## 不在范围

- 不支持在线歌词、封面下载、更新检查或网络依赖。
- 不承诺所有 MP4 编码；首要验收为 MP4 + AAC。
- 不删除手机源文件，不实现文件移动。
- 不新增多队列或定制队列恢复架构。
- 未配置正式 release keystore，不作为商店发布产物。

## 用户验收步骤

1. 安装“本地听歌”覆盖旧包，再安装“多听课程”；确认二者各一个图标、可同时打开，且橙色耳机图标仅用于“多听课程”。
2. 首次进入主页确认 MP3/MP4 都可见；切换 MP3、MP4、分类筛选。
3. 在“媒体库整理”中勾选项目加入两个分类；确认“全部”仍显示所有未隐藏项目。
4. 在单曲菜单选择“从媒体库移除（不删除手机文件）”，确认不会出现系统删除文件授权；刷新媒体库后确认不显示；在“已移除内容”勾选恢复，确认仅恢复所选内容且文件从未删除。
5. 播放视频 A 超过 15 秒后切换视频 B，再分别从首页、分类、搜索和队列手动回到 A，确认恢复到最近进度；播放至结束前 30 秒以内后退出并重开，确认从 0:00 开始。确认自动下一首不跳回旧进度。
6. 播放 MP4，确认竖屏画面；点击画面进入全屏并返回；锁屏后确认声音、通知栏和上一首/下一首仍正确。
7. 打开“诊断与日志”，确认可复制摘要并可按需导出 ZIP。
8. 在手机外放、媒体音量最大时，打开“设置 → 播放选项 → 外放强音”，分别播放 MP3 与 MP4；确认声音持续、锁屏后台不停止。该功能不承诺突破手机扬声器的物理最大声压。
