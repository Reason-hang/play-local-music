# 产品范围与验收

状态：2026-10-10 当前源码为 1.7.9／42，双 App 交互需求与实现后审计修复已实施；最新本地交付为 1.7.9，1.7.9 APK 已构建核验。最终双变体各 108 项通过、Release Lint 0 Error／Fatal（本地 139、课程 146 条警告）；新增三项 Android 10 收藏权威源回归已通过；真实提供方与升级仍待验。详见 [当前执行计划](03-双App交互修复需求与执行计划.md) 和 [实现后审计](../05-测试与验收/07-1.7.9实现后代码审计与修复报告.md)，原机与真实提供方仍待验收。

数据隔离口径：隐藏、分类、置顶、进度等应用私有状态按 applicationId 隔离；收藏沿用公共 Favorite 播放列表，不承诺收藏关系按 App 隔离。

## 已纳入范围

| 模块 | 当前行为 | 验收重点 |
| --- | --- | --- |
| 本地播放 | MP3；MP4 容器内 AAC 音轨 | 扫描、播放、切歌、队列 |
| 视频 | 播放页内预览；点击进入横屏全屏；同一时刻仅绑定一个视频输出；每个视频以 MediaStore ID 与路径哈希双身份独立断点续播 | 竖屏有画面、全屏画面连续、返回后进度和队列连续；从首页、分类、搜索、队列手动重开均恢复正确位置 |
| 外放强音 | 设置 → 播放选项中的默认关闭开关；使用 PCM 动态压缩与 4 dB 安全增益提升手机扬声器的感知响度 | MP3、MP4 音轨均可开关；满媒体音量下无异常中断或明显破音；蓝牙/有线耳机回归不受影响 |
| 后台 | 既有前台媒体服务与 MediaSession | 熄屏、通知栏、蓝牙 |
| 首页 | 三行歌曲主标题、小字号、无副标题；移除专辑/流派/发行日期标签；紧凑模式使用更低行高；骰子图标表示随机播放 | 长标题可读、标签数量收敛、紧凑模式密度和图标含义直观 |
| 播放目标一致性 | 同一媒体身份与队列快照解析点击；失效行拒绝派发；无缝更新使用单项替换，保留当前项进度 | 核对所点项、当前媒体、索引、进度及下一首；旧 ExoPlayer 四项失败、新实现六项通过，原机组合触摸仍待验 |
| 首页播放条 | 首页及列表场景常驻；无媒体显示“请选择歌曲／课程”并禁用无效控制；就绪后应用最新页面状态 | 冷启动不滚动、清空队列、后台返回、长标题与末项安全留白 |
| 全屏手势 | 中央双击复用 MediaSession 的暂停／继续语义；保留单击、底部按钮和进度条 | 缓冲／结束／断连不串状态；控件操作不触发双重切换，真实手势待验 |
| 置顶分隔 | 两类共存时使用主题色分隔；不增加行或改变队列索引 | 空／全置顶无多余边界，双主题与多列布局正确 |
| 整理 | MP3/MP4 筛选；分类多归属；单曲菜单和整理页均可非破坏性移出；已移除内容可多选恢复 | 重扫后隐藏不回流，手机文件不变；早期记录显示为“历史移除记录” |
| 收藏与置顶 | 歌曲行提供爱心收藏；“收藏”筛选进入长期收藏列表；更多菜单可手动置顶/取消置顶；收藏与置顶独立，取消置顶不删除收藏关系；收藏请求排队并共享幂等写入，Android 10 及以下保留 Reader 播放列表抽象，Android 11 及以上使用公共文件锁 | 爱心与播放器/收藏播放列表一致；置顶项目在当前歌曲列表顶部；取消置顶后恢复当前排序；两个 App 的应用私有置顶状态互不覆盖 |
| 双应用 | “本地听歌”与“多听课程”使用不同应用 ID 和本地状态；课程版固定火焰橙 `#FF4E00`，使用白底居中的橙色耳机图标 | 同机可同时显示两个图标、课程版图标同时用于启动、锁屏大图与通知小图标、互不覆盖、互不共享隐藏/进度/分类记录 |
| 诊断 | 复制脱敏摘要及最近 20 条播放状态；用户主动导出 ZIP | 无自动外发、无路径、URI 或标题泄露 |

## 不在范围

- 不支持在线歌词、封面下载、更新检查或网络依赖。
- 不承诺所有 MP4 编码；首要验收为 MP4 + AAC。
- 不删除手机源文件，不实现文件移动。
- 不新增多队列或定制队列恢复架构。
- 未配置正式 release keystore，不作为商店发布产物。

## 用户验收步骤

1. 安装“本地听歌”覆盖旧包，再安装“多听课程”；确认二者各一个图标、可同时打开，且橙色耳机图标仅用于“多听课程”。
2. 首次进入主页确认 MP3/MP4 都可见；切换 MP3、MP4、分类筛选。
3. 在“媒体库整理”中勾选项目加入两个分类；确认“全部”仍显示所有未隐藏项目。
4. 在歌曲列表点爱心收藏一首 MP3 和一项课程；切换“收藏”筛选，确认两者出现，取消其中一项后确认它从收藏列表消失；再从播放器底部爱心修改另一项，确认列表同步。
5. 在歌曲更多菜单选择“置顶”，确认项目移动到当前列表顶部；再选择“取消置顶”，确认它回到原排序且收藏关系仍保留。分别在两个 App 操作，确认置顶互不影响。
6. 在单曲菜单选择“从媒体库移除（不删除手机文件）”，确认不会出现系统删除文件授权；刷新媒体库后确认不显示；在“已移除内容”勾选恢复，确认仅恢复所选内容且文件从未删除。
7. 播放视频 A 超过 15 秒后切换视频 B，再分别从首页、分类、搜索和队列手动回到 A，确认恢复到最近进度；播放至结束前 30 秒以内后退出并重开，确认从 0:00 开始。确认自动下一首不跳回旧进度。
8. 播放 MP4，确认竖屏画面；点击画面进入全屏并返回；锁屏后确认声音、通知栏和上一首/下一首仍正确。
9. 打开“诊断与日志”，确认可复制摘要并可按需导出 ZIP。
10. 在手机外放、媒体音量最大时，打开“设置 → 播放选项 → 外放强音”，分别播放 MP3 与 MP4；确认声音持续、锁屏后台不停止。该功能不承诺突破手机扬声器的物理最大声压。

11. 分别冷启动两个 App，不滚动确认播放条可见；清空队列确认空态与禁用按钮，滚到末项确认无遮挡。
12. 在置顶／收藏／筛选列表点击当前媒体，核对实际媒体、进度和下一首；两区共存时确认主题分隔，空或全置顶无多余线。
13. 全屏中央双击暂停／继续，覆盖缓冲、结束、单击、倍速及进度条操作；确认一次双击只切换一次。
14. 在隔离收藏列表验证快速重复、授权成功／拒绝／重建和双 App 交替更新；Android 10 及以下另验 Reader 与 MediaStore 播放列表一致，Android 11 及以上另验文件锁与提供方。旧版／外部软件不遵守锁时不承诺并发安全。

上述为待执行的用户验收步骤，不代表真机通过；覆盖安装须使用同包名、兼容签名的新包，保留原媒体与公共收藏，不卸载主力 App 做破坏性验证。
