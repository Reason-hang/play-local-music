## 第一章 产品边界

### 1.1 保留能力

- MediaStore 本地扫描与歌曲列表。
- 本地 MP3 播放，以及 MP4 容器中 AAC 音轨的音频播放；MP4 不显示画面。
- MP3 与 MP4 + AAC 共用顺序/循环/随机、队列、播放列表、后台播放、锁屏媒体控制和蓝牙媒体按键。
- 界面沿用上游布局，目标语言为简体中文。

### 1.2 本次关闭能力

- 删除 `INTERNET`、`ACCESS_NETWORK_STATE` 和图片读取权限入口。
- 隐藏歌词按钮、歌词设置、歌词小部件设置、在线/外链更新入口。
- 隐藏均衡器菜单与调用路径。
- 保留歌词、封面和均衡器底层代码，不做全量重构或依赖清理。
- 不新增应用内年份标签、永久忽略、定制队列恢复或复杂播放进度恢复。

## 第二章 验收标准

1. Release APK 可安装，包名、版本号和 SHA-256 可复核。
2. APK 合并清单不包含 `INTERNET`、`ACCESS_NETWORK_STATE`、`READ_MEDIA_IMAGES` 或 `READ_MEDIA_VISUAL_USER_SELECTED`。
3. 简体中文资源可编译，关键页面不显示英文默认文案。
4. 自动化测试、Lint、Release 构建均有实际命令和退出结果。
5. MediaStore 视频集合中只有 MP4 + AAC 文件进入歌曲列表；无 AAC 音轨的 MP4 不进入。
6. 飞行模式下的扫描、MP3/MP4 + AAC 播放和队列主流程不依赖网络。
7. 红米 K80 Pro 真机验收单独记录；重点验证 MP4 + AAC 开始播放、熄屏后持续出声、锁屏通知控制、蓝牙切歌；没有设备时不得把静态结果写成真机通过。

## 第三章 风险与未覆盖项

- 本次重点承诺 MP3 与 MP4 + AAC；MP4 内的 MP3、Opus、AC-3 等其他音频编码不在本次验收范围，会被扫描逻辑排除。
- 仅播放 MP4 的音轨，不提供视频画面、画中画或视频进度体验。
- HyperOS 后台限制、锁屏通知和蓝牙行为仍需红米 K80 Pro 实机证据。
- 未删除底层歌词/封面/均衡器代码，依赖树仍可能包含其间接库；这符合方案 B。
