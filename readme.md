# 本地听歌

状态：SelfBuilt 本地播放器；当前目标版本：1.4.1。

本地听歌基于 Gramophone 二次开发，仅提供本地媒体库播放：MP3 与包含 AAC 音轨的 MP4。MP4 可在播放页点击画面进入全屏播放；锁屏、通知栏、蓝牙、队列与后台播放沿用既有 Media3 `MediaSession` 服务。

## 主要能力

- 本地扫描 MP3、MP4 + AAC；MP4 在播放页显示画面，点击画面进入横屏全屏，左上角返回；切换和锁屏时只保留一个视频输出，音频仍由前台媒体服务持续播放。
- 首页歌曲标题最多两行，不显示“未知音乐人”副标题；保留歌曲、音乐人、文件夹、文件系统、歌单标签。
- 首页快捷筛选：全部、MP3、MP4 和自定义分类。
- 媒体库整理：勾选媒体加入多个自定义分类；“移出媒体库”只写应用私有状态，不删除或移动手机文件，可从“恢复已移除内容”恢复。
- 上一首：只要队列存在上一项即跳转上一项；第一项回到 0:00。应用内和全屏视频页均提供 0.75、1、1.3、1.5、1.7、2 倍预设。
- 设置 → 诊断与日志：一键复制脱敏摘要；按需导出完整 ZIP；不自动联网、发送或读取剪贴板。

## 安装

安装 `outputs/本地听歌-1.4.1.apk`。该包保留 `org.akanework.gramophone.debug` 作为应用 ID，以覆盖此前已安装的同包版本；文件名不含 `debug`，但在未提供正式 keystore 前仍是 SelfBuilt 签名，不能作为商店发布包。
