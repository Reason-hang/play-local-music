# 本地听歌

状态：SelfBuilt 本地播放器；当前版本：1.7.2。

本地听歌基于 Gramophone 二次开发，仅提供本地媒体库播放：MP3 与包含 AAC 音轨的 MP4。MP4 可在播放页点击画面进入全屏播放；锁屏、通知栏、蓝牙、队列与后台播放沿用既有 Media3 `MediaSession` 服务。

## 主要能力

- 本地扫描 MP3、MP4 + AAC；MP4 在播放页显示画面，点击画面进入横屏全屏，左上角返回；切换和锁屏时只保留一个视频输出，音频仍由前台媒体服务持续播放。
- 每个视频独立断点续播：以 MediaStore ID 和路径哈希的双身份、时长和修改时间识别同一视频。首页、分类、搜索使用媒体展开后的真实目标项；队列切换会先保存旧视频，再带入目标视频进度。播放中最多每 15 秒保存一次，暂停、切换、移出任务和服务销毁立即保存。手动重新打开才恢复；自动下一集和循环不会跳回历史位置；播完前 30 秒或总时长 10% 内视为已看完，从头播放。
- 设置 → 播放选项 → 外放强音：默认关闭，面向手机扬声器跑步外放。它使用 PCM 动态压缩与固定安全增益提高感知响度，不需要耳机；不会突破手机硬件的最大声压，原音源已很响时提升有限。
- 首页歌曲主标题最多三行并缩小字号，不显示“未知音乐人”副标题；保留歌曲、音乐人、文件夹、文件系统、歌单标签。
- 首页快捷筛选：全部、MP3、MP4 和自定义分类。
- 媒体库整理：勾选媒体加入多个自定义分类；单曲菜单和整理页的“从媒体库移除”只写应用私有状态，不删除或移动手机文件；“已移除内容”支持勾选多项恢复。早期版本遗留记录会显示为“历史移除记录”，可一次性恢复，手机文件不受影响。
- 上一首：只要队列存在上一项即跳转上一项；第一项回到 0:00。应用内和全屏视频页均提供 0.75、1、1.3、1.5、1.7、2 倍预设。
- 设置 → 诊断与日志：一键复制最近 20 条脱敏播放事件与崩溃摘要；按需导出完整 ZIP；不自动联网、发送或读取剪贴板。

## 安装

| 安装包 | 应用 ID | 用途 |
| --- | --- | --- |
| `outputs/本地听歌-1.7.2.apk` | `org.akanework.gramophone.debug` | 覆盖此前的“本地听歌”安装。 |
| `outputs/多听课程-1.7.2.apk` | `org.akanework.gramophone.course.debug` | 白底居中的橙色耳机图标、火焰橙主题，可与“本地听歌”同时安装，数据相互隔离。 |

两个 APK 文件名均不含 `debug`，但在未提供正式 keystore 前仍是 SelfBuilt 签名，不能作为商店发布包。
